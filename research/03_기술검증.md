# 03. 기술 검증: 에뮬레이터에서 차량 신호와 위치 (2026-10-22)

1차 제출 데모(대기 자동 기록, ETA 알림)에 필요한 신호를 Pleos Connect Emulator v2.1.0에서 **읽고 바꿀 수 있는지** 확인했다.

## 결과 요약

| 신호 | 앱에서 읽기 | 에뮬레이터에서 바꾸기 | 비고 |
|---|---|---|---|
| GPS 위치 | O (`LocationManager` GPS) | O (`adb emu geo fix`) | |
| 속도 | O (`CarPropertyManager` `PERF_VEHICLE_SPEED`) | O (Virtual Console API) | 단위가 **m/s** (80 km/h → 22.22) |
| 기어 | O (`GEAR_SELECTION`) | O (Virtual Console API) | 4 = P, 8 = D. `CURRENT_GEAR`는 4에서 바뀌지 않아 쓰지 않음 |
| 내비 | 미확인 | - | 내비 앱(`ai.umos.maps.android.navigation.app`)과 Pleos 내비 서비스는 설치되어 있음. NaviHelper SDK로 ETA를 읽는 건 ETA 작업 때 확인 |
| Pleos FusedLocation | 미확인 | - | 서비스(`ai.pleos.playground.service.location.fused`)는 설치되어 있음. SDK 사용 승인 여부와 함께 확인 |

**결론: 대기 자동 기록 데모에 필요한 위치·속도·기어는 모두 에뮬레이터에서 재현할 수 있다.** 1차 개발은 Android 표준 API(`LocationManager`, `CarPropertyManager`)로 시작하고, 승인이 나면 Pleos FusedLocation으로 바꾼다.

## 신호 바꾸기

[tools/vehicle-sim.sh](../tools/vehicle-sim.sh)로 한 줄씩 바꿀 수 있다.

```bash
tools/vehicle-sim.sh geo 36.9922 127.0026   # 위치를 평택으로
tools/vehicle-sim.sh drive 60               # 기어 D, 60 km/h
tools/vehicle-sim.sh stop                   # 기어 P, 0 km/h
tools/vehicle-sim.sh state                  # 현재 기어·속도
```

### 동작 원리

- **위치:** 에뮬레이터 콘솔 명령 `adb emu geo fix <경도> <위도>`. 경도가 먼저다.
- **기어·속도:** Pleos Virtual Console(`adb forward tcp:8088 tcp:8088` 후 `http://127.0.0.1:8088`)에 HTTP API가 있다.
  - `POST /vehicle/gear?gear=Park|Reverse|Neutral|Drive`
  - `POST /vehicle/controls?speed_kph=0~240`
  - `GET /vehicle/state`
  - **주의:** 브라우저 세션이 `POST /browser/session?client=<id>`로 1초마다 살아 있음을 알려야 신호 변경을 받는다. 없으면 `{"error":"emulator_inactive"}`가 돌아온다. 스크립트가 이 세션을 잠깐 유지해 준다.
- 셸 명령(`adb shell cmd car_service ...`)으로 차량 속성을 바꾸는 방법은 막혀 있다. 에뮬레이터가 배포용(user) 빌드라 root와 car_service 디버그 명령을 쓸 수 없다.

## 앱에서 읽기

검증용 화면 `VehicleProbeActivity`를 디버그 빌드에만 넣어 두었다 (`android/app/src/debug/`). 신호를 logcat 태그 `IeoProbe`로 출력한다.

```bash
adb shell am start --user 10 -n com.ieo.app/.debug.VehicleProbeActivity
adb logcat -s IeoProbe
```

### 확인한 주의점

- **앱은 user 10에서 돈다.** 이 에뮬레이터는 운전자 프로필이 user 10이다. 권한을 adb로 줄 때 `--user 10`을 붙여야 한다. 붙이지 않으면 권한이 없는 것으로 나온다.
  ```bash
  adb shell pm grant --user 10 com.ieo.app android.car.permission.CAR_SPEED
  adb shell pm grant --user 10 com.ieo.app android.permission.ACCESS_FINE_LOCATION
  ```
  실제 앱에서는 실행 중에 권한을 요청하는 화면을 만든다.
- **속도 단위는 m/s다.** km/h로 바꾸려면 3.6을 곱한다.
- **속도 이벤트가 자주 온다.** 값이 같아도 약 0.1~0.2초마다 이벤트가 온다. 앱에서 정차·주행 판단에 쓸 때는 값을 모아 상태가 바뀔 때만 처리해야 한다(NFR-001 CPU 5% 기준).
- **GPS 위치에는 속도가 0으로 찍힌다.** `geo fix`로 순간이동시키기 때문이다. 속도는 위치가 아니라 `PERF_VEHICLE_SPEED`에서 읽는다.
