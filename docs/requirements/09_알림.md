# 09. 알림 (Notification)

## 목적

모든 도메인의 외부 발송(주선사, 수하인, 가족 등)을 한곳에서 처리한다. 발송 채널, 템플릿, 중복 방지, 발송 기록을 관리한다. 차량 안에서 차주에게 말하는 음성 안내는 [10_음성_안전UX.md](10_음성_안전UX.md)에서 다룬다.

## 결정 (2026-11-13): 문자·알림톡은 보내지 않는다

PM과 맞춘 내용이다. 주선사·차주·가족에게 가는 **알림 문자와 카카오 알림톡을 모두 뺐다.** 주선사는 콘솔 화면에서, 차주는 차량 앱 알림(SSE)과 음성으로 본다. 문자가 남는 곳은 **로그인 인증번호** 하나다.

- 서버: `BrokerNotifier`와 도착 예정 문자(TRIP-021·022), 대기 증빙·인수증 사진 도착 문자, 담당자 초대·단골 연결 요청 안내 문자를 지웠다. `Trip.notifiedEta`·`etaSharedAt`과 `TripResponse.etaSharedAt`도 없앴다 (운영 DB의 `trips.notified_eta`, `eta_shared_at` 칸은 남아 있어도 된다)
- 차량 앱: 홈의 "주선사에게 도착 시각을 알렸어요" 줄과 1분마다 다시 묻던 확인을 뺐다
- 콘솔에 주선사용 알림 목록(종 아이콘)은 아직 없다. 배차 요청은 홈·오더 목록의 대기 수로, 인수증 사진·대기 증빙·도착 예정은 운행 상세에서 본다

아래 표의 채널은 2026-11-13 결정에 맞췄다.

| 종류 | 받는 사람 | 트리거 | 채널 | 우선순위 |
|---|---|---|---|---|
| ETA | 주선사 | 운송 중 계속 | 콘솔 운행 화면 (알림 없음) | P1 |
| 인수 확인 링크 | 수하인 | 하차지에서 차량 화면의 QR로 보여 준다 (문자 발송 안 함) | QR | P2 |

| 단골 연결 요청 | 차주 | 주선사가 번호로 연결 요청 (BRK-002). 가입한 차주에게만 | 앱 알림 (휴대폰 알림함에서 누르면 단골 주선사 화면, 차량은 배너만). 미가입 번호는 보내지 않고, 그 번호로 가입하면 요청이 보인다 | P2 |
| 지정 오더 | 차주 | 단골 주선사가 나에게만 보이는 오더를 올리거나 지정을 바꿈 (BRK-011) | 앱 알림 (휴대폰 푸시를 누르면 오더 탭의 그 오더, 차량은 배너·음성) | P2 |
| 조건 맞는 새 오더 | 차주 | 저장한 조건에 맞는 오더 등록 | 미룸 (2026-11-14). 나중에 앱 푸시 (주행 중 음성 한 줄) | P3 |
| 결제 예정·실패 | 차주, 주선사 | 정기결제 3일 전, 결제 실패 | 앱·콘솔 화면 (미정) | P3 |
| 미수금 알림 | 차주 | 지급 예정일 경과 | 미룸 (2026-11-14). 지금은 장부 화면의 못 받은 돈으로 본다. 음성은 하지 않는다 (08 장부 결정) | P3 |
| 가족 안심 공유 | 차주가 지정한 가족 | 운행 시작·귀가 예정 | 뺌 (알림톡을 쓰지 않아 보낼 길이 없다) | - |

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| NOTI-001 | 도메인은 `발송 요청(종류, 받는 사람, 변수)`만 보내고, 채널 선택과 템플릿 적용은 알림 도메인이 한다 | P1 |
| NOTI-002 | ~~1차 데모는 SMS로 보내고, 2차 PT 전까지 카카오 알림톡으로 바꾼다~~ 뺌 (2026-11-13). 문자는 로그인 인증번호에만 쓴다 | - |
| NOTI-003 | 같은 운행·같은 종류의 발송은 정해진 간격 안에 다시 보내지 않는다 (예: ETA 재알림 30분) | P1 |
| NOTI-004 | 모든 발송을 기록한다: 종류, 받는 사람, 채널, 결과, 시각 | P1 |
| NOTI-005 | 밤 10시~아침 7시에는 수하인에게 보내지 않는다. 주선사는 설정을 따른다 | P2 |
| NOTI-006 | 받는 사람의 전화번호는 운행이 끝나고 30일 뒤 지운다 | P2 |
| NOTI-007 | 발송은 서버에서 비동기로 처리한다. 외부 발송 서비스 장애가 다른 기능을 막지 않는다 | P1 |

## 구현 상태 (2026-11-06)

- 차주 앱 알림(배차 확정·마감·만료)은 됨. "앱 푸시"는 FCM 대신 **SSE**: 차량 앱이 로그인한 동안 `GET /api/notifications/stream`을 붙잡고 서버가 밀어 준다. Pleos Connect SDK에 푸시가 없고 Google 서비스(FCM)가 있는지 확인되지 않아서다. 앱이 꺼져 있던 동안의 알림은 다시 붙을 때 마지막 id 다음부터 받는다. 설계: [design/06](../design/06_주선사_인계_작업내용.md) 13장
- 2026-11-09: 주선사 문자 흐름을 붙임. 대기 증빙 보내기(WAIT-022), 도착 시각 알림(TRIP-021·022: 첫 ETA, 50%, 도착 30분 전, 도착, 15분 이상 변경). 받는 사람은 그 회사의 첫 담당자. Ieo에 없는 주선사는 번호가 없어 보내지 않는다. 수하인 ETA 알림은 하지 않기로 했다 (2026-11-09)
- 2026-11-13: 위 주선사 문자 흐름과 초대·단골 요청 안내 문자를 모두 뺐다 (맨 위 결정)
- **인증번호 문자는 아직 실제로 나가지 않는다.** `LogSmsSender`가 서버 로그에만 남긴다. 업체를 정하고 `SmsSender` 구현체를 바꾸면 나간다
  - 2026-11-14: 그래서 공모전 기간에는 **운영 서버도 인증번호를 응답에 담아 앱 화면에 "시연용 인증번호"로 보여 준다** (환경변수 `IEO_AUTH_SHOW_DEMO_CODE=true`). 아무 번호로나 로그인할 수 있으니, 문자 업체를 붙이는 날 이 값을 끈다
- 2026-11-13: 단골 연결 요청 알림(`DRIVER_LINK_REQUESTED`)을 붙임. 알림이 배차 요청 대신 단골 요청(`driverLinkId`)을 가리킬 수 있다. 운영 DB: `scripts/notifications-driver-link.sql`
- 2026-11-13: **휴대폰 푸시(FCM)를 붙였다. 키를 넣으면 켜진다.** 같은 알림을 앱 안(SSE)과 휴대폰 푸시로 함께 보낸다. 서버는 data 메시지(type·notificationId·orderId·driverLinkId·제목·본문)로 보내고, 휴대폰이 알림을 그려 누르면 그 화면(단골 요청 → 단골 주선사, 배차 확정 → 내 배차)을 연다. 앱 안 배너를 눌러도 같은 화면으로 간다
  - 서버: 환경변수 `FIREBASE_CREDENTIALS`(Firebase 서비스 계정 키 JSON 내용이나 파일 경로)가 비어 있으면 보내지 않는다. 휴대폰이 로그인할 때 `PUT /api/notifications/push-token`, 로그아웃 전에 `POST /api/notifications/push-token/remove`. 앱을 지워 못 쓰게 된 토큰은 보낼 때 지운다. 운영 DB: `scripts/push-tokens.sql`
  - 휴대폰: `app/google-services.json`(커밋하지 않음)이 있으면 그 값으로 Firebase를 켠다. 안드로이드 13 이상은 로그인 뒤 알림 권한을 한 번 묻는다
  - 차량(Pleos)은 구글 서비스가 있는지 몰라 SSE를 그대로 쓴다
- 2026-11-14: **주선사가 확정된 배차를 취소하면 기사님에게 알린다** (`DISPATCH_CANCELED`). 문구: "{회사}에서 배차를 취소했어요. {상차지}에서 {하차지}까지, 내 배차에서 뺐어요". 지정 오더 알림 문구도 태그에 맞춰 "{회사}에서 단골 오더를 보냈어요"로 바꿨다. 운영 DB: `scripts/dispatch-canceled.sql` (targeted-orders.sql 다음)
- 2026-11-14: **차량 알림을 Pleos 에뮬레이터에서 확인했다 (SSE).** 단골 연결 요청, 지정 오더, 배차 확정, 배차 취소를 주선사 쪽에서 보내자 몇 초 안에 차량 배너가 떴고 음성으로 읽었다. 앱이 꺼져 있던 동안 온 알림은 다시 켰을 때 이어서 받았다. 음성은 에뮬레이터 음성 서비스가 느려 늦게 나온 적이 있다(실차에서 다시 볼 것)
  - Pleos 에뮬레이터(Pleos_Connect_v2.1.0)에는 구글 서비스(`com.google.android.gms`)가 없어 **차량 앱은 FCM 토큰을 받을 수 없다.** 그래서 차량은 SSE를 그대로 쓰고, 시동이 꺼져 있을 때는 휴대폰 FCM 푸시가 받는다
- 2026-11-14: **기본 알림은 끝.** 조건 맞는 새 오더·미수금 알림·주선사 콘솔 알림 목록은 미뤘다 (아래 미결). 발송 기록(NOTI-004~007)은 보낼 문자·알림톡이 없어져 인증번호 문자를 실제로 붙일 때 다시 본다
