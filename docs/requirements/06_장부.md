# 06. 장부 (Ledger)

## 목적

**운행이 곧 장부**가 되게 한다. 운행이 끝나면 장부 한 줄이 자동으로 생기고, 경비는 운전 중 말로 남기며, 받을 돈(미수금)을 추적한다. 기획서 기능 ⑨ 자동 장부와 ⑦ 하루 마감 수익 리포트를 담당한다.

배경: 실제 차주(아버님)는 운행 내역을 종이 메모장에 적는다. 정보망 앱은 자기 앱에서 잡은 오더만 보여 주고, 장부 전용 앱은 운행이 끝난 뒤 직접 입력해야 한다.

## 사용자 시나리오

1. 평택→대구 운행이 끝나면 장부에 한 줄이 생긴다: 날짜, 상하차지, 주행거리 312km, 대기 2시간 10분, 운임 45만 원, 대기비 1만 원(청구 예정), 주선사, 결제 방식 "인수증", 지급 예정일.
2. 주유소를 나서며 "주유 15만 원"이라고 말한다. 경비에 기록된다.
3. 홈 맨 위에서 오늘 운행 건수와 실수익을 본다. 자세한 것은 장부 탭에서 본다.
4. 지급 예정일이 지났는데 입금 확인이 안 된 건이 있으면 장부에 빨간색으로, 홈에 "○○물류 45만 원, 지급일 3일 지남" 한 줄로 보여 준다.
5. 운행이 끝나면 운송료 세금계산서가 준비되고, 휴대폰에서 한 번 눌러 차주 명의로 발행한다 (자동 발행은 프로 이상).
6. 5월에 종합소득세 신고용 엑셀을 내려받는다.

### 운송료 전자세금계산서

운송료 세금계산서는 운송한 차주 명의로 발행하고, 주선사를 거쳐 운임을 받는 경우 비고란에 주선사 등록번호를 적는다(국토부 Q&A). 기사님이 매번 홈택스에 들어가 직접 발행하는 번거로움을 없앤다.

- 지금 방식(아버님, 2026-11-12 확인): 집 노트북에서 홈택스로, **운행 1건마다 계산서 1장**을 발행한다. 공동인증서를 갖고 있다
- 연동(2026-11-12 정함): **볼타 API의 대리 정발행.** 홈택스는 발행 API가 없어서 국세청 등록 발행 대행 업체(ASP)를 쓴다. 볼타는 정발행·수정발행 건당 90원, 월 기본료 없음, 웹훅, 테스트 키(국세청 전송·과금 없는 가상 발행). 팝빌·바로빌은 건당 200원 안팎에 기사님마다 업체 회원 가입이 필요하다
- 인증서는 볼타가 보관한다. 이에오는 인증서 파일과 비밀번호를 저장하지 않고 서버로 받지도 않는다
- 위수탁 발행(이에오 인증서 하나로 차주 명의 발행)은 인증서가 필요 없지만, 플랫폼이 수탁자가 될 수 있는지 세무 검토 전까지 쓰지 않는다
