# 06. 장부 (Ledger)

## 목적

**운행이 곧 장부**가 되게 한다. 운행이 끝나면 장부 한 줄이 자동으로 생기고, 경비는 운전 중 말로 남기며, 받을 돈(미수금)을 추적한다. 기획서 기능 ⑨ 자동 장부와 ⑦ 하루 마감 수익 리포트를 담당한다.

배경: 실제 차주(아버님)는 운행 내역을 종이 메모장에 적는다. 정보망 앱은 자기 앱에서 잡은 오더만 보여 주고, 장부 전용 앱은 운행이 끝난 뒤 직접 입력해야 한다.

## 사용자 시나리오

1. 평택→대구 운행이 끝나면 장부에 한 줄이 생긴다: 날짜, 상하차지, 주행거리 312km, 대기 2시간 10분, 운임 45만 원, 대기비 1만 원(청구 예정), 주선사, 결제 방식 "인수증", 지급 예정일.
2. 주유소를 나서며 "주유 15만 원"이라고 말한다. 경비에 기록된다.
3. 시동을 끄면 하루 요약을 들려준다: "오늘 2건, 운임 82만 원, 경비 21만 원, 실수익 61만 원. 공차 48km, 대기 3시간 20분이었습니다."
4. 지급 예정일이 지났는데 입금 확인이 안 된 건이 있으면 "○○물류 45만 원 지급 예정일이 3일 지났습니다"라고 알린다.
5. 5월에 종합소득세 신고용 엑셀을 내려받는다.

## 기능 요구사항

### 수입 기록

| ID | 요구사항 | 우선순위 |
|---|---|---|
| LEDG-001 | `TripCompleted`가 오면 장부 항목을 자동으로 만든다: 날짜, 상하차지, 주행거리(Vehicle SDK), 대기·작업 시간, 운임, 주선사, 결제 방식 | P2 |
| LEDG-002 | 대기비는 "청구 예정" 부가 수입으로 따로 기록하고, 받으면 "받음"으로 바꾼다 | P2 |
| LEDG-003 | 차주가 장부 항목의 운임과 결제 방식을 고칠 수 있다 | P2 |
| LEDG-004 | Ieo로 등록하지 않은 운행도 정차 중 화면에서 직접 추가할 수 있다 | P2 |

### 경비 기록

| ID | 요구사항 | 우선순위 |
|---|---|---|
| LEDG-010 | 음성으로 경비를 기록한다: "주유 15만 원", "통행료 2만 3천 원", "식대 9천 원". 분류와 금액을 인식해 다시 읽어 준다 | P2 |
| LEDG-011 | 경비 분류: 주유, 통행료, 식대, 정비, 보험, 주차, 기타 | P2 |
| LEDG-012 | 주유 경비가 기록되면 연료량 변화(Vehicle SDK)와 비교해 실측 연비 계산에 쓴다 | P3 |

### 미수금

| ID | 요구사항 | 우선순위 |
|---|---|---|
| LEDG-020 | 지급 예정일 = 선불·착불은 운행일, 인수증은 인수증 전달일 + 주선사별 정산 주기(기본 30일) | P2 |
| LEDG-021 | 차주가 "받음"으로 표시하기 전까지 미수금으로 본다 | P2 |
| LEDG-022 | 지급 예정일이 지나면 다음 시동 때 음성으로 알리고, 장부 화면에 빨간색(경고)으로 표시한다 | P2 |
| LEDG-023 | 주선사별 미수금 합계와 평균 지급 소요일을 보여 준다. 이 값은 주선사 신뢰 지표로 넘긴다 ([07_주선사.md](07_주선사.md)) | P3 |

### 리포트 (기능 ⑦)

| ID | 요구사항 | 우선순위 |
|---|---|---|
| LEDG-030 | 그날 마지막 시동을 끌 때 하루 요약을 음성과 화면으로 보여 준다: 운행 건수, 운임 합계, 경비 합계, 실수익, 공차 거리·비율, 대기 시간, 청구 가능 대기비 | P2 |
| LEDG-031 | "마지막 시동"은 시동을 끈 뒤 30분 안에 다시 켜지 않은 것으로 판단하고, 다음 시동 때 어제 요약을 들려준다 | P2 |
| LEDG-032 | 월별·주선사별 매출, 경비, 실수익 추이를 보여 준다 | P2 |
| LEDG-033 | 기간을 정해 엑셀(CSV)로 내보낸다. 종합소득세·부가세 신고에 쓸 수 있는 열 구성으로 한다 | P2 |
| LEDG-034 | 세금계산서 자동 발행 | P3 |

## 데이터

| 엔티티 | 주요 필드 |
|---|---|
| LedgerEntry | id, driverId, tripId?, date, description, fare, distanceKm, waitMinutes, brokerId?, paymentType, expectedPaymentDate, paidAt?, source(AUTO/MANUAL) |
| ExtraIncome | id, ledgerEntryId, type(WAIT_FEE/ETC), amount, status(CLAIMABLE/CLAIMED/PAID) |
| Expense | id, driverId, tripId?, date, category, amount, memo?, source(VOICE/MANUAL) |
| DailySummary | driverId, date, tripCount, fareTotal, expenseTotal, netProfit, emptyKm, emptyRatio, waitMinutes, claimableWaitFee |

- [ ] `[인터뷰]` 주선사별 실제 정산 주기
- [ ] 입금 확인을 자동화할 방법 (오픈뱅킹 등)은 P3로 검토
