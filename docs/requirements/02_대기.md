# 02. 대기 (Waiting)

## 목적

상하차지에서 기다린 시간을 **차주가 아무것도 누르지 않아도** 자동으로 기록하고, 청구할 수 있는 대기비를 계산해 증빙으로 남긴다. 기획서 기능 ③을 담당한다. 1차 제출 데모의 중심 기능이다.

배경: 1시간 이상 대기한다는 응답이 64%, 대기 시간을 운임에 반영받지 못한다는 응답이 81%다(상용차매거진 2025.4). 증빙이 없어서 대기비를 청구하지 못한다.

## 사용자 시나리오

1. 차주가 평택 상차지 반경 200m 안으로 들어와 차를 세운다(기어 P 또는 주차 브레이크).
2. 3분이 지나면 앱이 "평택 상차지에 도착하셨어요? 2시부터 대기로 기록할까요?"라고 묻는다. 차주가 "응"이라고 하면 화면에 노란 대기 타이머가 돈다.
3. 2시간 10분 뒤 지게차가 오자 차주가 "상차 시작"이라고 말한다. 대기가 끝나고 작업 시간 기록이 시작된다.
4. 상차를 마치고 출발하면 앱이 "상차 끝내고 출발할까요?"라고 묻는다. "응"이라고 하면 작업 기록도 끝난다.
5. 이 주선사의 대기비 정책(2시간 초과 시 30분당 1만 원)에 따라 청구 가능 대기비 1만 원이 계산된다.
6. 차주가 "대기 증빙 보내"라고 하면 주선사에게 증빙 링크가 간다.

## 구간 정의

```
 도착 감지 ── 확인 ── 대기 ─────────── 작업 시작 ─── 작업 ─── 이탈
 (내비 알림·정차)  (15초)                    (음성·버튼)             (지오펜스 밖 또는 주행)
```

- **대기 시간** = 대기 시작 ~ 작업 시작. 대기 시작은 확인했으면 감지한 시각, 직접 [대기 시작]을 눌렀으면 누른 시각
- **작업 시간** = 작업 시작 ~ 이탈
- 작업 시작 신호가 없으면 진입부터 이탈까지 전체를 "체류 시간"으로만 기록하고, 대기와 작업을 나누지 않는다. 대기비 계산에는 체류 시간을 쓰지 않는다.

## 기능 요구사항

| WAIT-003 | 지오펜스 안에서 잠깐 움직였다 다시 서는 것(자리 이동, 5분 이내)은 대기가 이어진 것으로 본다 | P1 |
| WAIT-004 | "상차 시작"·"하차 시작" 음성이나 버튼으로 대기를 끝내고 작업 시간을 시작한다 | P1 |
| WAIT-005 | 떠남 감지: 지오펜스를 30초 넘게 벗어나거나 시속 20km 이상으로 1분 넘게 달리면 음성과 15초 창으로 "하차 끝내고 운행을 마칠까요?"(상차지는 "상차 끝내고 출발할까요?")라고 묻는다. 확인하면 감지한 시각으로 떠남을 기록한다. 아니거나 대답이 없으면 지오펜스 안으로 다시 들어오기 전에는 묻지 않고, 차주가 "운행 완료"·"상차 끝, 출발"을 직접 누른다 (2026-11-11 변경) | P1 |

## 상태

```
 대기 아님 ──(지오펜스 안 + 3분 정차)──▶ 대기 중 ──(작업 시작 신호)──▶ 작업 중
     ▲                                     │                            │
     └──────────── 이탈 ◀──────────────────┴────────────────────────────┘
```

## 대기비 계산 예

정책: 무료 2시간, 30분 단위, 단위당 1만 원, 상한 5만 원

| 대기 시간 | 계산 | 청구 가능 |
|---|---|---|
| 1시간 40분 | 무료 시간 이내 | 0원 |
| 2시간 10분 | 초과 10분 → 1단위(올림) | 1만 원 |
| 4시간 5분 | 초과 2시간 5분 → 5단위 | 5만 원 |
| 6시간 | 초과 4시간 → 8단위 → 상한 적용 | 5만 원 |

- 단위 시간은 올림으로 계산한다. 올림/내림은 정책 항목으로 둔다.

## 미결 사항

- [ ] 에뮬레이터에서 위치(GPS)를 바꾸는 방법 확인 (Virtual Console 카드 목록에 없음). 안 되면 테스트용 가짜 위치 입력 모드를 둔다
- [ ] `[인터뷰]` 대기비를 실제로 주는 곳의 기준(무료 시간, 금액), 지금 어떻게 증빙하는지
- [ ] `[인터뷰]` 상하차 "작업 시작"을 기사가 직접 알 수 있는 시점인지 (지게차 도착, 호출 등)
- [ ] 3분 정차 기준이 신호 대기·정체와 헷갈리지 않는지 실차 데이터로 검증
- [ ] 실제 화물차에서 주차 브레이크 신호(`PARKING_BRAKE_ON`)가 들어오는지 확인. 안 오면 "세움"은 기어 P로만 판단한다 (03 배차 추천도 같은 신호를 쓴다)
