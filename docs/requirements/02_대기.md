# 02. 대기 (Waiting)

## 목적

상하차지에서 기다린 시간을 **차주가 아무것도 누르지 않아도** 자동으로 기록하고, 청구할 수 있는 대기비를 계산해 증빙으로 남긴다. 기획서 기능 ③을 담당한다. 1차 제출 데모의 중심 기능이다.

배경: 1시간 이상 대기한다는 응답이 64%, 대기 시간을 운임에 반영받지 못한다는 응답이 81%다(상용차매거진 2025.4). 증빙이 없어서 대기비를 청구하지 못한다.

## 사용자 시나리오

1. 차주가 평택 상차지 반경 200m 안으로 들어와 차를 세운다(기어 P 또는 주차 브레이크).
2. 3분이 지나면 앱이 "평택 상차지에 도착하셨어요? 2시부터 대기로 기록할까요?"라고 묻는다. 차주가 "응"이라고 하면 화면에 노란 대기 타이머가 돈다.
3. 2시간 10분 뒤 지게차가 오자 차주가 "상차 시작"이라고 말한다. 대기가 끝나고 작업 시간 기록이 시작된다.
4. 상차를 마치고 출발하면 작업 기록도 끝난다.
5. 이 주선사의 대기비 정책(2시간 초과 시 30분당 1만 원)에 따라 청구 가능 대기비 1만 원이 계산된다.
6. 차주가 "대기 증빙 보내"라고 하면 주선사에게 증빙 링크가 간다.

## 구간 정의

```
 도착 감지 ── 확인 ── 대기 ─────────── 작업 시작 ─── 작업 ─── 이탈
 (내비 알림·정차)  (15초)                    (음성·버튼)             (지오펜스 밖 또는 주행)
```

- **대기 시간** = 대기 시작 ~ 작업 시작. 대기 시작은 확인했으면 감지한 시각, 직접 [대기 시작]을 눌렀으면 누른 시각
- **작업 시간** = 작업 시작 ~ 이탈
- 작업 시작 신호가 없으면 진입부터 이탈까지 전체를 "체류 시간"으로만 기록하고, 대기와 작업을 나누지 않는다. 대기비 계산에는 체류 시간을 쓰지 않는다.

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| WAIT-001 | 도착 감지: 내비가 "목적지 도착"을 알리거나, 상하차지 지오펜스(반지름 200m) 안에서 3분 이상 정차하면 도착한 것으로 본다. 정차는 기어 P 또는 주차 브레이크가 채워진 상태다. P가 없는 화물차(수동·자동화 수동 변속기)는 주차 브레이크로 판단한다. 지오펜스를 벗어나거나 정차가 풀리면 처음부터 다시 센다. 감지만으로는 대기를 시작하지 않는다 (2026-11-11 변경) | P1 |
| WAIT-007 | 도착을 감지하면 음성과 화면으로 15초 동안 "도착하셨어요? N시부터 대기로 기록할까요?"라고 묻는다. 음성으로 먼저 묻고, 화면 창은 이에오가 화면에 보일 때만 띄운다. 확인하면 감지한 시각부터 대기를 시작한다. 15초 안에 대답이 없거나 "아직"이면 창을 닫고, 같은 정차 중에는 다시 묻지 않는다. 음성 대답은 언제든, 화면 터치는 정차(기어 P 또는 주차 브레이크)일 때만 받는다 (2026-11-11) | P1 |
| WAIT-008 | 차주는 언제든 [대기 시작]으로 직접 대기를 시작할 수 있다. 지오펜스 밖(정문 밖 도로의 줄 등)이어도 된다. 시각은 누른 때다. 버튼은 상하차지 3km 안에 들어오면 늘 보이고(도착 안내를 시작하는 거리와 같다), 정차(기어 P 또는 주차 브레이크)일 때만 눌린다 (2026-11-11) | P1 |
| WAIT-002 | 대기 시작을 음성으로 알리고, 화면에 대기 타이머를 노란색(대기 상태색)으로 보여 준다 | P1 |
| WAIT-003 | 지오펜스 안에서 잠깐 움직였다 다시 서는 것(자리 이동, 5분 이내)은 대기가 이어진 것으로 본다 | P1 |
| WAIT-004 | "상차 시작"·"하차 시작" 음성이나 버튼으로 대기를 끝내고 작업 시간을 시작한다 | P1 |
| WAIT-005 | 지오펜스를 벗어나거나 시속 20km 이상으로 1분 넘게 달리면 체류를 끝낸다 | P1 |
| WAIT-006 | 차주가 대기·작업 구간 시각을 나중에 고칠 수 있다. 고친 기록에는 "수정됨" 표시와 원래 값이 남는다 | P2 |
| WAIT-010 | 대기비 정책을 주선사별로 둔다: 무료 대기 시간, 단위 시간, 단위 금액, 상한 | P1 |
| WAIT-011 | 대기가 끝나면 정책에 따라 청구 가능 대기비를 계산해 보여 준다. 정책이 없으면 시간만 기록한다 | P1 |
| WAIT-012 | 무료 대기 시간을 넘기는 순간 "지금부터 대기비가 붙습니다"라고 음성으로 알린다 | P2 |
| WAIT-020 | 대기 증빙 리포트를 만든다: 상하차지, 진입·작업 시작·이탈 시각, 대기 시간, 위치 이력 지도, 청구 가능 금액 | P1 |
| WAIT-021 | 리포트는 웹 링크로 공유하고 PDF로 내려받을 수 있다 (프로 이상) | P2 |
| WAIT-022 | 차주가 요청하면 주선사에게 리포트 링크를 보낸다 ([09_알림.md](09_알림.md)). 베이직은 대기 시간·청구 가능 금액 보기까지, 증빙 전송은 프로 이상 ([12_요금제_결제.md](12_요금제_결제.md)). 1차 제출 데모에서는 플랜 구분 없이 시연한다 | P1 |
| WAIT-023 | 대기 기록은 상하차지 통계로 넘긴다 ([05_상하차지.md](05_상하차지.md)) | P2 |
| WAIT-024 | 대기를 주선사가 판단할 수 있게, 상하차지 3km 안에서 잰 위치(5분마다)를 대기 기록과 함께 남기고, 도착 감지·확인(또는 직접 시작)·작업 시작·이탈 시각을 같이 적는다. 증빙(WAIT-020)에 이 위치와 시각을 보여 준다. 지금 서버는 운행의 마지막 위치 하나만 들고 있다가 운행이 끝나면 지운다 (2026-11-11) | P1 |
| WAIT-024 | 대기비를 장부에 운행의 부가 수입(청구 예정)으로 넣는다 ([06_장부.md](06_장부.md)) | P2 |

## 상태

```
 대기 아님 ──(지오펜스 안 + 3분 정차)──▶ 대기 중 ──(작업 시작 신호)──▶ 작업 중
     ▲                                     │                            │
     └──────────── 이탈 ◀──────────────────┴────────────────────────────┘
```

## 대기비 계산 예

정책: 무료 2시간, 30분 단위, 단위당 1만 원, 상한 5만 원

| 대기 시간 | 계산 | 청구 가능 |
|---|---|---|
| 1시간 40분 | 무료 시간 이내 | 0원 |
| 2시간 10분 | 초과 10분 → 1단위(올림) | 1만 원 |
| 4시간 5분 | 초과 2시간 5분 → 5단위 | 5만 원 |
| 6시간 | 초과 4시간 → 8단위 → 상한 적용 | 5만 원 |

- 단위 시간은 올림으로 계산한다. 올림/내림은 정책 항목으로 둔다.

## 미결 사항

- [ ] 에뮬레이터에서 위치(GPS)를 바꾸는 방법 확인 (Virtual Console 카드 목록에 없음). 안 되면 테스트용 가짜 위치 입력 모드를 둔다
- [ ] `[인터뷰]` 대기비를 실제로 주는 곳의 기준(무료 시간, 금액), 지금 어떻게 증빙하는지

- [ ] 3분 정차 기준이 신호 대기·정체와 헷갈리지 않는지 실차 데이터로 검증
