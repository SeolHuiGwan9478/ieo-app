# 05. 상하차지 (Site)

## 목적

상하차지마다 **오더에 담기지 않는 현장 정보**(높이 제한, 지게차 유무, 평균 대기 시간)를 쌓고, 차주가 그곳에 다가갈 때 음성으로 알려 준다. 기획서 기능 ⑤를 담당한다.

배경: 주차장 높이를 몰라 진입하지 못하거나, 지게차가 없어 상하차가 늦어지는 일이 생긴다. 아틀란트럭에 차주들이 올린 상하차지 팁이 약 10만 건에 이를 만큼 현장 정보 수요가 크다.

## 사용자 시나리오

1. 칠곡 물류센터까지 3km 남았을 때 앱이 말한다: "칠곡 물류센터는 높이 제한 3.5미터, 지게차 있음. 평균 대기 1시간 20분입니다."
2. 차주가 상차를 마치고 출발하면서 "지게차 기사 점심시간은 12시부터 1시"라고 말한다. 이 음성 메모가 칠곡 물류센터 정보에 추가된다.

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| SITE-001 | 상하차지를 장소로 관리한다: 이름, 주소, 좌표, 지오펜스 반경 | P1 |
| SITE-002 | 운행 등록 때 같은 주소(좌표 100m 이내)의 기존 상하차지가 있으면 그것을 쓴다 | P1 |
| SITE-003 | 대기 기록이 쌓이면 평균 대기 시간, 평균 작업 시간, 요일·시간대별 대기를 계산한다 ([02_대기.md](02_대기.md)) | P2 |
| SITE-004 | 차주가 남긴 정보를 항목으로 저장한다: 높이 제한, 지게차 유무, 주차 가능 여부, 자유 메모 | P2 |
| SITE-005 | 이탈 직후 1분 동안 "메모 남길까요?"라고 묻고, 음성 메모를 받아 텍스트로 저장한다 | P2 |
| SITE-006 | 상하차지 반경 3km에 들어오면 정보 카드 요약을 음성으로 읽어 준다. 정보가 없으면 읽지 않는다 | P2 |
| SITE-007 | 정차 중 화면에서 정보 카드 전체(지도, 항목, 최근 메모 5개)를 볼 수 있다 | P2 |
| SITE-008 | 메모는 작성자 외 다른 차주에게도 보이며, 작성자는 익명으로 표시한다 | P2 |
| SITE-009 | 다른 차주가 "도움 돼요"를 누를 수 있고, 오래되거나 신고된 메모는 뒤로 미룬다 | P3 |
| SITE-010 | 평균 대기 시간은 배차 추천의 실수익 표시에 쓴다 ([03_배차추천.md](03_배차추천.md) REC-012) | P2 |
