# 08. 계정·차량 (Account & Vehicle)

## 목적

차주와 차량 정보를 관리한다. 다른 도메인이 쓰는 기본 정보(톤수, 차종, 연비, 정산 계좌 없이도 쓸 수 있는 최소 프로필)를 제공한다.

## 기능 요구사항

### 차주

| ID | 요구사항 | 우선순위 |
|---|---|---|
| ACC-001 | 휴대폰 번호 인증으로 가입·로그인한다. 차량 화면에서는 휴대폰으로 받은 인증번호를 입력하거나 QR로 로그인한다 | P1 |
| ACC-002 | 가입 때 위치 수집, 주선사 공유, 음성 데이터 처리에 각각 동의를 받는다. 주선사 공유는 선택 항목이다 | P1 |
| ACC-003 | 프로필: 이름, 휴대폰, 화물운송 자격 여부(선택). 사업자 정보(상호, 사업자등록번호, 대표자)는 선택 입력이고, 내 정보에서 미리 넣어 둘 수 있다. 가입 때는 묻지 않고 장부 내보내기에 쓴다 | P2 |
| ACC-004 | 탈퇴하면 개인정보와 위치 기록을 지운다. 주선사에게 이미 전달된 증빙은 주선사 쪽 보관 정책을 따른다 | P2 |
| ACC-005 | 휴대폰의 내 정보에서 로그인된 차량 목록을 보고, 차량별로 로그아웃시킬 수 있다. 끊으면 그 차량의 다음 요청부터 막히고 휴대폰 로그인은 그대로다 | P2 |
| ACC-006 | 내 정보에서 선택 동의(주선사 공유, 음성, 마케팅)를 켜고 끌 수 있다. 바꿀 때마다 이력을 쌓는다. 필수 동의는 철회할 수 없고 탈퇴로 안내한다. 주선사 공유를 끄면 주선사 콘솔에 위치·도착 예정 시각·진행률을 주지 않고 도착 시각 문자도 보내지 않는다. 단골 연결을 수락하면 공유에 동의한 것으로 기록한다. 음성 데이터 처리를 끄면 차량 앱이 마이크를 켜지 않고 화면 버튼으로 진행한다 | P2 |
| ACC-007 | 필수 서류 4종이 모두 승인되면 "인증 차주" 마크를 홈과 내 정보의 이름 옆에 붙인다. 서류는 휴대폰 내 정보 > 서류에서 한 장씩 찍거나 앨범에서 골라 올린다 승인된 서류를 다시 내면 새 서류가 승인될 때까지 인증이 풀린다(2026-11-14, 화면에 안내) | P2 |
| ACC-008 | 내 정보 수정에서 이름과 휴대폰 번호를 바꾼다. 번호는 새 번호로 인증번호를 받아 확인해야 바뀌고(`POST /api/users/me/phone`), 다른 계정이 쓰는 번호는 막는다. 차량 앱은 이름만 바꾸고 번호는 휴대폰에서 바꾼다 | P2 |

ACC-001의 휴대폰 로그인·차량 QR 로그인과 주선사 콘솔의 소셜 로그인(Google·카카오) 설계(흐름도, API, 토큰): [../design/01_로그인.md](../design/01_로그인.md)

### 차량

| ID | 요구사항 | 우선순위 |
|---|---|---|
| VEH-001 | 차량을 등록한다: 차량 번호, 톤수, 차종(카고, 윙바디, 탑차, 냉동·냉장 등), 높이. 차주 한 명에 차 한 대이고(서류도 한 벌), 휴대폰 내 차량에서 번호까지 바로 고친다. 번호·톤수·차종을 바꾸면 서버가 자동차등록증을 반려해 다시 받고 그동안 미인증이다. 제원(높이·너비·길이·총중량·축 수)은 자유롭게 고친다 | P1 |
| VEH-002 | 차량 높이는 상하차지 높이 제한과 비교해 경고하는 데 쓴다 ([05_상하차지.md](05_상하차지.md)) | P2 |
| VEH-006 | 트럭 폭·길이·총중량·축 수는 선택 입력이다. 입력하면 TMAP 화물차 경로와 통행료 차종에 쓰고, 비어 있으면 톤수별 기본값을 쓴다 (폭 1~3m, 길이 2~20m, 총중량 1~40톤, 축 2~6개) | P2 |
| VEH-003 | Vehicle SDK의 누적 연비로 차량 실측 연비를 저장하고, 실수익 계산에 쓴다. 차량 연비가 없으면 차주가 휴대폰 내 차량에 넣은 평소 연비(선택, 1.5~15km/L)를 쓰고, 그것도 없으면 톤수별 기본값을 쓴다 ([03_배차추천.md](03_배차추천.md)) | P2 |
| VEH-004 | Pleos 차량에서 처음 로그인하면 그 차량을 차주의 기본 차량으로 연결한다 | P1 |
| VEH-005 | 차량 한 대에 차주 한 명을 기본으로 한다. 교대 운전은 P3로 검토 | P3 |

## 데이터

| 엔티티 | 주요 필드 |
|---|---|
| Driver | id, name, phone, consentLocation, consentBrokerShare, consentVoice, createdAt |
| Vehicle | id, driverId, plateNumber, tonnage, bodyType, heightM, measuredKmPerLiter?, pleosDeviceId? |
| DriverHome | driverId, siteId (귀가 방향 추천용, 선택) |

## 미결 사항

- [ ] 차량 화면 로그인 방식(인증번호 입력 vs 휴대폰 QR) 결정. 차량 화면에서 키보드 입력이 불편한 정도 확인
- [x] Pleos 차량 고유 식별자를 앱에서 얻을 수 있는지 확인: Vehicle SDK `CarInfo.getVINInfo`(권한 `pleos.car.permission.CAR_INFO`)로 차대번호를 읽는다. 에뮬레이터에서 실제 값이 오는지는 확인 전
