# 07. 주선사 (Broker)

## 목적

주선사가 **스스로 Ieo를 쓰게 만드는** 웹 콘솔을 제공한다. 주선사는 배차한 차량의 위치·ETA, 대기 증빙, 전자인수증을 무료로 받고, 그 대가로 배차를 Ieo에 등록한다. 이렇게 등록된 배차가 배차 추천의 물량이 된다(기획서 9장 전략 B). 신뢰 지표(기능 ⑧)도 이 도메인에 둔다.

## 사용자 시나리오

1. ○○물류 배차 담당자가 웹 콘솔에 가입하고, 단골 차주(Ieo 사용자)를 전화번호로 초대한다.
2. 평택→대구 배차를 등록하고 차주에게 보낸다. 차주가 차량에서 "수락"하면 운행이 시작된다.
3. 담당자는 화주에게 "어디쯤이냐"는 전화를 받으면 콘솔에서 바로 위치와 ETA를 확인한다.
4. 상차지 대기가 길어지자, 차주가 보낸 대기 증빙 링크를 화주에게 그대로 전달해 대기비를 청구한다.
5. 다른 차주가 Ieo에서 "수락 요청"을 보낸 오더를 확인하고 확정한다.

## 기능 요구사항

### 가입과 연결

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-001 | 주선사가 사업자 정보(상호, 사업자등록번호, 운송주선사업 허가 번호)로 가입한다. 담당자 여러 명을 둘 수 있다 | P2 |
| BRK-002 | 주선사가 차주를 전화번호로 초대하고, 차주가 수락하면 연결된다. 연결된 차주의 위치만 볼 수 있다 | P2 |
| BRK-003 | 주선사별 대기비 정책과 정산 주기를 설정한다 ([02_대기.md](02_대기.md), [06_장부.md](06_장부.md)) | P2 |

### 배차

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-010 | 배차를 등록한다: 상하차지, 상하차 가능 시간, 화물 종류, 톤수·차종, 운임, 결제 방식 | P2 |
| BRK-011 | 배차를 특정 차주에게 직접 보내거나, 추천 대상(공개 오더)으로 올린다 | P2 |
| BRK-012 | 차주의 수락 요청을 확정하거나 거절한다. 10분 안에 응답하지 않으면 요청이 만료된다 ([03_배차추천.md](03_배차추천.md) REC-023) | P2 |

### 운행 확인

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-020 | 진행 중인 운행 목록을 지도와 표로 본다: 차주, 상태, 현재 위치, ETA | P2 |
| BRK-021 | 운행별 대기 증빙과 전자인수증을 보고 내려받는다 | P2 |
| BRK-022 | 화주에게 보낼 공유 링크(위치·ETA, 대기 증빙)를 만든다 | P2 |

### 신뢰 지표 (기능 ⑧)

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-030 | 주선사별로 실제 운행 데이터에서 지표를 계산한다: 평균 지급 소요일, 지급 지연 비율, 대기비 지급 비율, 연결 차주들이 겪은 평균 대기 시간 | P3 |
| BRK-031 | 배차 추천 카드에 주선사 지표를 함께 보여 준다 | P3 |
| BRK-032 | 지표는 표본이 충분할 때(완료 운행 20건 이상)만 공개한다 | P3 |

## 데이터

| 엔티티 | 주요 필드 |
|---|---|
| Broker | id, name, businessNumber, licenseNumber, settlementDays, createdAt |
| BrokerMember | id, brokerId, name, phone, role |
| BrokerDriverLink | brokerId, driverId, status(INVITED/LINKED/REVOKED), linkedAt |
| BrokerMetrics | brokerId, avgPaymentDays, latePaymentRatio, waitFeePaidRatio, avgWaitMinutes, sampleCount, updatedAt |

- 배차는 [03_배차추천.md](03_배차추천.md)의 `Order`, 대기비 정책은 [02_대기.md](02_대기.md)의 `WaitPolicy`를 쓴다.
