# 07. 주선사 (Broker)

## 목적

주선사가 **스스로 Ieo를 쓰게 만드는** 웹 콘솔을 제공한다. 무료 플랜으로 오더를 올리고, 배차한 차량의 위치·ETA, 대기 증빙, 전자인수증을 받는다. 이렇게 올라온 오더가 Ieo 오더 마켓의 물량이 된다(기획서 9장 전략 B). 정회원은 **실제 운행 데이터 리포트**를 받는다. 신뢰 지표(기능 ⑧)도 이 도메인에 둔다.

오더 등록과 배차 확정의 상세 요구사항은 [11_배차.md](11_배차.md), 플랜 구성은 [12_요금제_결제.md](12_요금제_결제.md)에 있다.

이 도메인은 다른 개발자가 맡는다. 서버에 이미 있는 것과 남은 일: [../design/02_주선사_인계.md](../design/02_주선사_인계.md), 웹 콘솔 작업 안내: [../design/03_어드민_인계.md](../design/03_어드민_인계.md)

## 사용자 시나리오

1. ○○물류 배차 담당자가 웹 콘솔에 가입하고, 단골 차주(Ieo 사용자)를 전화번호로 초대한다.
2. 평택→대구 배차를 등록하고 차주에게 보낸다. 차주가 차량에서 "수락"하면 운행이 시작된다.
3. 담당자는 화주에게 "어디쯤이냐"는 전화를 받으면 콘솔에서 바로 위치와 ETA를 확인한다.
4. 상차지 대기가 길어지자, 차주가 보낸 대기 증빙 링크를 화주에게 그대로 전달해 대기비를 청구한다.
5. 다른 차주가 Ieo에서 "수락 요청"을 보낸 오더를 확인하고 확정한다.

## 기능 요구사항

### 가입과 연결

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-001 | 주선사가 사업자 정보(상호, 사업자등록번호, 운송주선사업 허가 번호)로 가입한다. 허가 번호가 없으면 오더를 올릴 수 없다. 담당자는 플랜에 따라 여러 명 둘 수 있다 | P2 |
| BRK-002 | 주선사가 차주를 전화번호로 초대하고, 차주가 수락하면 연결된다. 연결된 차주의 위치만 볼 수 있다 | P2 |
| BRK-003 | 주선사별 대기비 정책과 정산 주기를 설정한다 ([02_대기.md](02_대기.md), [06_장부.md](06_장부.md)) | P2 |

### 배차

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-010 | 콘솔에서 오더를 등록·수정·내린다 (상세: [11_배차.md](11_배차.md) DSP-001~006) | P2 |
| BRK-011 | 오더를 단골 차주에게 지정해 보내거나, 오더 마켓에 공개한다 | P2 |
| BRK-012 | 차주의 배차 요청 목록을 보고 확정하거나 거절한다 (상세: DSP-020~025) | P2 |

### 운행 확인

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-020 | 진행 중인 운행 목록을 지도와 표로 본다: 차주, 상태, 현재 위치, ETA | P2 |
| BRK-021 | 운행별 대기 증빙과 전자인수증을 보고 내려받는다 | P2 |
| BRK-022 | 화주에게 보낼 공유 링크(위치·ETA, 대기 증빙)를 만든다 | P2 |

### 신뢰 지표 (기능 ⑧)

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-030 | 주선사별로 실제 운행 데이터에서 지표를 계산한다: 평균 지급 소요일, 지급 지연 비율, 대기비 지급 비율, 연결 차주들이 겪은 평균 대기 시간 | P3 |
| BRK-031 | 배차 추천 카드에 주선사 지표를 함께 보여 준다 | P3 |
| BRK-032 | 지표는 표본이 충분할 때(완료 운행 20건 이상)만 공개한다 | P3 |

### 정회원 운행 데이터 리포트

화물맨 정회원(월 33,000원)은 공유 화물 기능으로 **올라온 오더의 단가(호가)와 물동량**을 보여 준다. Ieo 정회원은 차량에서 모은 **실제로 달린 결과**를 준다.

| ID | 요구사항 | 우선순위 |
|---|---|---|
| BRK-040 | 노선별 리포트: 실제 운임 분포(평균, 중앙값), 실제 소요 시간, 최근 추이. Ieo에서 완료된 운행 기준 | P3 |
| BRK-041 | 상하차지별 리포트: 평균 대기·작업 시간, 요일·시간대별 대기. 화주 견적과 대기비 청구 근거로 쓸 수 있게 내려받기 제공 | P3 |
| BRK-042 | 내 회사 리포트: 배차 건수, 평균 배차 확정 시간, 차량별 이행률, 대기비 청구 가능액 합계 | P3 |
| BRK-043 | 단골 차주 관리: 함께 일한 차주 목록, 이행 기록(정시 도착률, 취소율), 단골 지정 | P3 |
| BRK-044 | 리포트는 개별 차주를 알아볼 수 없게 집계한다. 표본이 10건 미만인 노선·상하차지는 보여 주지 않는다 | P3 |
| BRK-045 | 2차 PT에서는 샘플 데이터로 리포트 화면을 시연한다 | P2 |
