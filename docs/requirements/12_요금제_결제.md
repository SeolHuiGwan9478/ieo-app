# 12. 요금제·결제 (Plans & Billing)

## 목적

차주와 주선사 양쪽에 플랜을 나누어 서비스를 유지할 수입을 만든다. 플랜별 기능 범위, 구독 결제, 해지·환불, Ieo가 발행하는 구독료 영수증을 다룬다.

### 원칙

1. **오더 열람과 배차는 모든 플랜에서 무료다.** 기존 정보망(화물맨 차주 월 2.2만~5.5만 원)이 받는 "입장료"를 받지 않는다. 차주가 모여야 주선사가 오더를 올린다.
2. **돈과 직결되는 기능에 과금한다.** 세금계산서, 대기비 증빙, 장부 전체, 세무·금융 연계.
3. **월정액 구독만 받는다.** 오더·배차 건마다 받는 요금은 만들지 않는다 (2027.9 플랫폼법의 건당 중개수수료 금지).
4. **해지는 앱에서 바로 된다.** 기존 앱의 "탈퇴 후에도 자동결제", "환불 거절" 분쟁을 반복하지 않는다.

## 결제 정책 (2026-11-13)

기사님·주선사 플랜 결제에 공통으로 적용한다. 휴대폰 플랜 화면 맨 아래 **"?" 요금·결제 안내** 줄을 누르면 이 정책을 설명서처럼 장(플랜과 가격, 결제와 자동 갱신, 무료 체험, 해지와 환불, 결제가 안 될 때, 보상 쿠폰, 영수증)으로 나눠 보여 준다 (`PlanGuideScreen.kt`의 `PLAN_GUIDE`). 정책을 바꾸면 이 표와 그 목록을 함께 고친다.

| 항목 | 정책 | 근거 ID |
|---|---|---|
| 결제 단위 | 30일 단위로 결제한다. 운행·배차 건마다 받는 돈은 없다 (플랫폼법 건당 수수료 금지) | PLAN-008 |

## 보상 쿠폰: 주선사 늦은 취소 (DSP-034, 2026-11-13)

크레딧과 기간 이벤트는 만들지 않는다(2026-11-13 이벤트도 뺌). 보상은 **주선사가 늦게 배차를 취소했을 때** 기사님에게 주는 프로 이용일 **쿠폰** 하나뿐이다. 받는다고 바로 쓰이지 않고, 기사님이 [사용하기]를 눌러야 그 기사님의 플랜만 바뀐다.

| 항목 | 내용 |
|---|---|
| 언제 | 주선사가 상차 예정 2시간 안에(또는 지난 뒤) 배차를 취소했을 때 (`Cancellation.isLate()`, 주선사 취소) |
| 무엇 | 프로 3일 쿠폰 (가정값) |
| 한도 | 운행 하나에 한 장, 같은 기사님 30일에 3장까지 (주선사와 짜고 취소를 반복하는 일을 막는다) |
| 쓰기 | 휴대폰 플랜 화면 "내 쿠폰"에서 [사용하기] (`POST /api/plans/me/coupons/{id}/use`). 지금 프로(유료·체험·쿠폰)면 기간 끝에 3일을 더하고, 베이직이면 오늘부터 3일 프로가 되고 끝나면 결제 없이 베이직 |
| 기한 | 받은 날부터 90일. 지나면 "기간이 지났어요"로 남고 쓸 수 없다 |
| 기록 | `plan_coupons` (기사님, 운행, 일수, 이유, 받은 시각, 기한, 쓴 시각). 결제가 아니라 `plan_payments`에는 남기지 않는다 |
| 화면 | **쿠폰함** (휴대폰 플랜 화면의 "쿠폰함" 줄, 내 정보 플랜 카드의 "쿠폰 n장"): 위에 "쓸 수 있는 쿠폰 / 지난 쿠폰" 탭, 티켓 모양 쿠폰(왼쪽 "프로 이용권 · 프로 3일 · 주선사 늦은 취소 보상 · 2027.02.11까지 · D-90", 떼는 선 오른쪽 [사용하기] 또는 "사용 완료·기간 만료"). [사용하기]를 누르면 "언제까지 프로가 되는지" 한 번 더 묻고 쓴다. 맨 아래 "?" 쿠폰·요금 안내. 시안: `design/assets/plan-tickets/coupon-pro-days.svg`, `coupon-pro-days-used.svg` |
| 기사님 늦은 취소 | 돈·쿠폰을 빼지 않는다. 지금처럼 30일 3번이면 7일 배차 요청 제한 (DSP-033). 돈을 붙이면 배차 건과 묶여 건당 요금처럼 보일 수 있다 |
| 구독할 때 | 쿠폰으로 받은 날이 남은 채 구독하면 남은 날을 결제한 30일 뒤에 붙인다 |
