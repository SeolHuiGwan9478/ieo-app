# 12. 요금제·결제 (Plans & Billing)

## 목적

차주와 주선사 양쪽에 플랜을 나누어 서비스를 유지할 수입을 만든다. 플랜별 기능 범위, 구독 결제, 해지·환불, Ieo가 발행하는 구독료 영수증을 다룬다.

### 원칙

1. **오더 열람과 배차는 모든 플랜에서 무료다.** 기존 정보망(화물맨 차주 월 2.2만~5.5만 원)이 받는 "입장료"를 받지 않는다. 차주가 모여야 주선사가 오더를 올린다.
2. **돈과 직결되는 기능에 과금한다.** 세금계산서, 대기비 증빙, 장부 전체, 세무·금융 연계.
3. **월정액 구독만 받는다.** 오더·배차 건마다 받는 요금은 만들지 않는다 (2027.9 플랫폼법의 건당 중개수수료 금지).
4. **해지는 앱에서 바로 된다.** 기존 앱의 "탈퇴 후에도 자동결제", "환불 거절" 분쟁을 반복하지 않는다.

## 기능 요구사항

### 플랜과 권한

| ID | 요구사항 | 우선순위 |
|---|---|---|
| PLAN-001 | 차주·주선사마다 현재 플랜을 가진다. 가입하면 무료 플랜으로 시작한다 | P2 |
| PLAN-002 | 기능 사용 권한은 서버가 플랜으로 판단한다. 앱은 서버가 알려 준 권한 목록으로 화면을 그린다 | P2 |
| PLAN-003 | 무료 플랜에서 유료 기능을 누르면 무엇이 되는지 한 화면으로 보여 주고 업그레이드로 안내한다. 주행 중에는 안내하지 않는다 | P2 |
| PLAN-004 | 플랜을 내리면 쌓인 데이터는 지우지 않고 보기만 제한한다 (예: 지난달 장부는 보관, 다시 올리면 보임) | P2 |
| PLAN-005 | 프로 첫 1개월 무료 체험을 준다. 체험 종료 3일 전에 알린다 | P3 |
| PLAN-006 | 사용 한도(세금계산서 건수, 공유 링크 건수)를 세고, 80%와 100%에서 알린다 | P3 |

## 크레딧 (미정, 2026-11-12)

**크레딧은 13개 도메인 확인을 모두 마친 뒤 마지막에 한꺼번에 만든다 (2026-11-12 결정).** 그 전까지 크레딧이 필요한 곳은 아래 표와 서버 TODO로만 남긴다. 새로 생기면 이 표에 더한다.

구독료와 따로, 차주가 쌓고 쓰는 포인트를 둔다. 오더·배차 건마다 받는 요금이 아니라 보상·패널티용이다. 쓰는 곳(구독료 할인 등)과 금액은 아직 정하지 않았다.

| 쓰이는 곳 | 내용 | 코드 |
|---|---|---|
| 늦은 취소 (DSP-034) | 차주가 늦게 취소하면 돌려주지 않고, 주선사가 늦게 취소하면 돌려준다 | 서버 `DispatchCanceller`의 TODO |
| 상하차지 정보 남기기 (SITE-011) | 휴대폰에서 메모나 높이 제한·지게차·주차 정보를 남기면 소정의 크레딧. 같은 곳에 짧은 시간에 여러 번, 너무 짧은 메모는 주지 않는다 | 서버 `SiteService`의 TODO |
